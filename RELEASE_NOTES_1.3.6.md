# RPG Sheet 1.3.6 — Correção de dependência do build

## Correção

- Corrigida a dependência `supabase` no `pubspec.yaml` para a faixa compatível `^2.14.0`.
- A versão `2.15.4` usada anteriormente não estava disponível para resolução pelo `flutter pub get` no workflow.
- Mantidas integralmente as funcionalidades e alterações de backend da V1.3.5.
- Versão do app e cache do PWA atualizados para `1.3.6+106`.

## Versionamento

A partir desta versão, qualquer atualização distribuída — inclusive hotfix — avança a versão sequencial do RPG Sheet.
